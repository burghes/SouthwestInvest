INVEST SOUTH WEST · LOGO PACK (DRAFT v2, Nov 2026)
Replaces the "Invest in the South West" v1 pack.

WHAT CHANGED
  Name is now INVEST SOUTH WEST. All three words are the same size and weight (Oswald Bold, capitals).
  The compass mark is unchanged, so the v1 favicons and social avatar still work.

FILES
  svg/  Vector artwork, text outlined (no fonts needed). Use for print and web.
  png/  Transparent PNGs. Use in Word, PowerPoint and Canva.

VERSIONS
  horizontal = PRIMARY. Compass + two lines (INVEST / SOUTH WEST).
  one-line   = for long, shallow spaces only (web header, email signature, banner strips).
  stacked    = for narrow or square spaces (pull-up tops, posters).
  mark       = compass on its own (avatars, favicons, very small spaces).
  colour = on white or Mist. reverse = on Deep Sea or dark photos. mono-black / mono-white = one-colour use.

RULES
  Clear space: half the height of the compass on all sides.
  Minimum size: horizontal 25mm wide in print / 120px on screen (to test). Below that, use the mark.
  Never recolour, stretch, rotate, outline or add effects. The gold half of the needle always points south-west.

STILL TO CHECK BEFORE PUBLIC USE
  Formal trademark search (name and compass) · existing uses of "Invest South West" (e.g. BVCA event series)
  · domain · which body owns the mark.
